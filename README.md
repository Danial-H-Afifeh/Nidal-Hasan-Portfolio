# مكتب نضال حسن للتخليص الجمركي

الموقع التعريفي لمكتب نضال حسن للتخليص الجمركي في طرطوس. صُمم الموقع ليقدم صورة واضحة عن خدمات المكتب، ويعرض سجل الأعمال، ويوفر قنوات مباشرة للتواصل عبر الهاتف والبريد الإلكتروني وواتساب.

## أبرز أقسام الموقع

- صفحة رئيسية تعريفية متجاوبة مع مختلف أحجام الشاشات.
- عرض خدمات التخليص الجمركي والاستيراد والتصدير والاستشارات.
- سجل أعمال يعرض أحدث الأعمال مع أرشيف كامل للصور والفيديوهات.
- قسم للوثائق يتيح معاينة ملف البنود الجمركية وتنزيله.
- نموذج تواصل يفتح رسالة جاهزة في Gmail، مع خيار بديل للإرسال عبر واتساب.
- لوحة إدارة خاصة لإضافة الأعمال والوسائط وحذفها.

## التقنيات المستخدمة

- React 19
- Vite
- Supabase Authentication
- Supabase Database وStorage
- GitHub Pages للنشر

## إدارة المحتوى

من أسفل الموقع اضغط **إدارة المحتوى**، ثم سجّل الدخول بحساب Supabase المخصص للإدارة. بعد تسجيل الدخول يمكنك:

- إضافة عنوان ووصف وتصنيف وتاريخ للعمل.
- رفع صورة أو فيديو إلى Supabase Storage.
- نشر العمل ليظهر للزوار.
- حذف الأعمال المنشورة والوسائط المرتبطة بها.

## روابط ومعلومات قابلة للتعديل

- ملف البنود الجمركية يعتمد على المعرّف `DRIVE_FILE_ID` الموجود في [app.jsx](./app.jsx).
- بيانات الهاتف والبريد وواتساب موجودة في [app.jsx](./app.jsx).
- الصور الرئيسية للموقع موجودة في [public/](./public/).


للتشغيل المحلي، انسخ [.env.example](./.env.example) إلى ملف باسم `.env.local` في جذر المشروع، ثم أضف:

```env
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-public-key
VITE_SUPABASE_STORAGE_BUCKET=work-images
```

بعد تعديل الملف أعد تشغيل خادم Vite.
